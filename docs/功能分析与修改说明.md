# 音乐播放器 3.0.4：分析与修改说明

下载成功的原文件约 41.4 MiB。包名为 `com.sony.walkman.highresmediaplayer`，版本 3.0.4/30004，minSdk 与 targetSdk 均为 34。它是包含索尼 Walkman 播放器实现的原生 Android APK；此身份来自 manifest 和代码命名，未验证原包是否为索尼官方签发或是否曾被修改。

## 内置功能的静态发现

| 功能 | 依据与结论边界 |
|---|---|
| 本地音乐库与扫描 | manifest 声明 MediaScannerService/JobService、PlayerMediaProvider、MediaFolderProvider，接收存储挂载变化；类清单包含按曲目、专辑、艺人、文件夹等组织的实现。 |
| 后台播放与控制 | PlaybackService 声明为 mediaPlayback 前台服务；REA 反编译确认播放指令会进入请求队列，暂停会发送 PauseRequest；原版提供通知、小组件、媒体按键和循环/随机相关实现。 |
| 播放列表、收藏、歌词 | 清单中有 PlaylistEditor/M3uPlaylistUtil、Favorite*Editor、LyricParser/LyricModel 及对应界面；这是实现模块的静态存在性，未逐项运行验证。 |
| Walkman 界面与音效 | 设置创建代码/类清单含磁带界面、音效初始化、DSD参数等；布局/实现包含均衡器、DSEE、黑胶处理、DC相位线性器、DSD重制等。实际可见性、处理效果及机型支持需实机确认。 |
| USB音频/DAC | manifest、UsbPlayer/DacModePlayer/WmPlayer 及相关设置中存在实现，未连接USB设备验证。 |
| 原播放时长 | REA 设置代码确认按 WIRED_SE / WIRED_BTL 分开统计，200小时变色，用途是耳机接口煲机时长，不含每日记录，且部分机型隐藏。此次保留该功能。 |

manifest 未声明 INTERNET；检查到的主路径是本地音乐播放，未据此宣称穷尽所有系统代理通信或所有可能功能。

## 本次新增

1. 设置顶部增加“睡眠与听歌记录”：预设/自定义定时、取消、状态显示。
2. 计时到点后，在当前歌曲自然结束时请求原播放服务暂停；不关机。开启期间停止新的 gapless 预取，并为先前预载的下一曲增加切换后暂停兜底。
3. 按实际 PLAYING 状态记录今日、累计和每日历史；暂停、快进、倒退不计时，以 elapsedRealtime 测量时长、按本地日期分日，10秒检查点持久化。
4. 改为新包名共存，独立 provider、自定义权限和广播；原资源/素材不改，原类名和音频后端保留。

## 验证结果与尚未验证之处

已通过：新增Java编译、DEX汇编、35项计时断言、42项服务逻辑断言、最终DEX六个接入点检查、ZIP完整性、1940资源/素材条目保持、包名/权限/manifest解析、zipalign与v3签名验证。没有在此环境安装或运行 APK。

未 root ZX706 的共存可用性仍未知。原包不携带所需的 5 个索尼原生库，而是通过 System.loadLibrary 加载设备系统库。共存包增加可选 uses-native-library 声明，但这不能授予系统未公开的库或签名级权限；更换签名后是否仍可访问，必须实机验证。不能保证原高解析度音频及所有音效可用。

定时启用前已预载下一曲时，首次曲尾可能先发出极短下一曲声音后暂停。异常结束最多可能丢失最后约10秒统计，清除数据/卸载共存版会移除记录。统计只涵盖此共存版，不追踪系统原播放器。

## 实机验收建议

保留系统原版，在ZX706安装桌面名为“音乐播放器·睡眠统计”的共存APK，按原播放器提示授予音乐存储访问。先确认能打开、扫描和播放；再暂停一段时间确认不增加记录；用1分钟定时、较长歌曲确认到点后不立即中断、曲尾暂停。可再试锁屏、连续两首歌曲和跨午夜记录。若失败，记录具体安装错误或闪退日志，以区分包安装限制和索尼音频服务限制。
